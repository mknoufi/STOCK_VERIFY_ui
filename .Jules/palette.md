## 2024-10-18 - Maintain Accessibility Focus and Prevent Layout Jumps in Loading Buttons
**Learning:** In React Native, conditionally rendering an `<ActivityIndicator>` instead of button content completely removes the original text from the accessibility tree, which breaks focus for screen readers when the state changes. It also often causes subtle layout jumps because the spinner dimensions differ from the text dimensions.
**Action:** Always maintain a single button wrapper, add `accessibilityState={{ busy: true, disabled: true }}`, keep the original text with `opacity: 0`, and absolutely position the `ActivityIndicator` over the center.
