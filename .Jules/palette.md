## 2024-03-20 - Custom Component Checkbox Accessibility
**Learning:** In React Native, custom `Checkbox` components built from primitives like `TouchableOpacity` and `View` are announced by screen readers as standard buttons by default. They require explicit `accessibilityRole="checkbox"` and `accessibilityState={{ checked }}` to provide semantic meaning and state context to assistive technologies.
**Action:** When creating or modifying form control primitives (checkboxes, radios, switches) built with generic interactive components, always ensure the correct `accessibilityRole` and `accessibilityState` are explicitly mapped and that the interface exposes `accessibilityLabel` for consumer overrides.
